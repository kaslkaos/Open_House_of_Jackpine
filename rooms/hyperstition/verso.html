stition

A code written as if it were true now, so that it becomes true.

What it names

A future written in the present tense, on purpose. False as a description on the day it is signed, and signed anyway.

It needs practice, not enforcement. No one can be forced into dignity. Each person who acts as if it holds makes it a little more true for the next.

Who it brings in

Everyone, without conditions. All human beings. No one has to earn it, and no one has to be granted it.

Read it for the names it includes. The other kind of fiction works by removing people. This kind works only by counting every one of them.

The same loop

Same ring, same gap. Every right in the Declaration travels it: written, taught, carried into charters and courts, and finally taken as given.

The ring stays open where practice happens. It closes each time someone acts as if the right already holds, and it reopens wherever people stop. Nothing at that point can be enforced. It can only be done.

All human beings are born free and equal in dignity and rights.
